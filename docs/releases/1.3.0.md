# PicRope 1.3.0

## 统一备忘篮子

- 图片、文字和图文组合统一进入备忘篮子，移除绳子上的信封入口，以及托盘中的图片篮子、文字信封和新图片自动上绳重复入口。
- 操作与筛选按钮同一行，支持全部、待挂、图片、文字、图文及搜索；再次点击当前类型取消筛选。
- 左侧采用三列紧凑缩略图，整卡点击选中并预览，再点取消，支持多选、批量挂绳和删除。切换筛选时清除隐藏条目的勾选，避免误删除。
- 右侧统一显示图片和可直接编辑的完整文字，自动保存；保存失败保留草稿并阻止切换或关闭。可直接新建文字备忘。
- 两个自动上绳开关横向排列：新图片自动上绳管理图片和图文，新文字自动上绳仅管理纯文字。
- 沿用已有内容、颜色、混合排序及单条归档设置；归档继续采用月度文本与同ID图片。

## 预览与安装修复

- 图文组合详情中的图片支持双击打开原图，使用与单独图片相同的系统查看器。
- 安装器检测并比较本地版本：高版本安装包正常退出旧程序后自动安装；同版或低版询问是否继续。取消或程序未退出时不改动安装文件。

## 安装与更新

完整解压 `PicRope-1.3.0-windows-x64.zip` 后运行 `Install.cmd`，或在托盘中检查更新。更新保留数据、设置和归档。附带 SHA256 校验文件。1.3.0 高于此前所有 1.2.x 版本（含 1.2.85），可正常检查更新。
