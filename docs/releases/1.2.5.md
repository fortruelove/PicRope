# PicRope 1.2.5

修复 QQ 同时复制文字与图片时，图片无法自动收集或粘贴的问题。现在可读取混合内容中引用的本机缓存图片，并将文字作为图片备注一起保存、挂绳。

- 剪贴板「图片」「文字」自动获取开关独立并排，可分别开启和记忆。
- 兼容图片格式读取失败后的自动回退，支持 PNG/JPEG、位图、DIB/DIBV5、图片文件和本机 HTML 配图。
- 信封、篮子以及点击范围缩小一半，位置和弹窗锚点同步调整。
- 保留图文关联、拆分、手动粘贴、拖动排序、独立自动上绳和置顶绳子。

图片在本机处理，不执行剪贴板 HTML，不自动下载远程配图。QQ 缓存图片已失效时，仍保留能读取的文字。

自动组合图文需要同时开启托盘的图片、文字获取开关，并开启篮子自动上绳。手动粘贴不受自动获取开关影响。

## 安装和更新

下载 `PicRope-1.2.5-windows-x64.zip`，完整解压，退出正在运行的图绳后运行 `Install.cmd`。更新保留原有 data 文件夹和设置；安装包随附 SHA256 校验文件，不包含个人截图或测试数据。

已有支持应用内更新的版本，也可在托盘「更多操作」中选择「检查更新」。

## 1.2.5 安装修订

- 移除安装时对 WMI/CIM 进程查询的依赖，避免权限或服务异常导致安装中断。
- 按字面路径复制文件，兼容解压目录中的方括号等字符。
- 安装失败详情记录到解压目录的 `logs/latest.log`；应用运行日志位于安装目录的同名路径。
- 版本号仍为 1.2.5；已安装 1.2.5 的用户需要重新下载安装包，应用内更新不会重复安装同一版本。

### 启动取消处理修订

安装完成后，Windows 返回“启动操作已取消”（错误 1223）或拒绝自动启动时，不再误报整个安装失败；保留已安装文件、快捷方式和 data，并明确提示手动启动。启动错误码及详情单独写入安装日志。安装窗口保留处理结果，按任意键关闭；不自动重试或更改 Windows 安全设置。
