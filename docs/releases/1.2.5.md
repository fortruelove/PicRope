# PicRope 1.2.5

修复 QQ 同时复制文字与图片时无法读取配图：该剪贴板可能只有 UnicodeText、HTML Format 和 QQ 富文本，没有 PNG/Bitmap。现在从单张 HTML img 的本机 file URI 读取缓存图片，验证图片后转成 PNG 保存，并保留同一快照中的完整文字。自动与手动粘贴共用此路径。

只读取明确的本机文件，不执行 HTML，不下载远程图片，不访问 UNC 共享。缓存已失效时保留有效文字。

验证：构造 QQ 本机 HTML 图文用例，先观察失败，再修复通过；使用用户同一份真实 QQ 剪贴板只读检查，读取结果从 image=False/text=True 变为 image=True/text=True，未输出内容。

自动组合图文需要同时开启托盘的图片、文字获取开关，并开启篮子自动上绳。手动粘贴不受自动获取开关影响。
