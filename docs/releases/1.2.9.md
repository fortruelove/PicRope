# PicRope 1.2.9

- 图片篮子的“关联 / 编辑图文”和文字信封的“配图 / 编辑”按钮增加边框，与其他操作按钮保持一致。
- 篮子预览区及信封详情区右侧新增“删除时归档”开关，只影响当前预览的备忘。
- 未单独设置的条目跟随托盘全局设置；手动切换后保存为独立设置，切换条目或重启后仍保留。
- 单条选择关闭时永久删除，不进入归档；单条选择开启时，即使全局关闭也会归档。图文组合共同遵循同一个设置。
- 切换开关不立即归档或删除，删除时继续使用月度文本和对应图片ID格式。

## 安装与更新

完整解压 `PicRope-1.2.9-windows-x64.zip` 后运行 `Install.cmd`，保留现有数据、设置及归档。附带 SHA256 校验文件。

本次按指定版本号发布为 1.2.9。标准版本比较中 1.2.85 高于 1.2.9，因此已安装 1.2.85 的用户需要下载本安装包手动更新。
