## PicRope 1.2.3

基于 1.2.2 图文内容卡片版本，保留图文关联编辑、拆分、手动粘贴、独立自动上绳和置顶绳子。

- 图片、文字和图文组合卡片可以直接拖动排序，重启后保留顺序。
- 拖动时对应夹子和整条绳子高亮，并显示插入位置。
- 仅在绳子挂卡区域内松开鼠标才改变顺序；拖到其他应用或取消拖动不改序。
- 图片、文字、图文组合卡片和批量删除直接执行，无二次确认；图片仍移入系统回收站，组合卡片备注同步删除。
- 应用内检查更新、下载校验和下载链接统一使用 fortruelove/PicRope。

### 安装

下载 `PicRope-1.2.3-windows-x64.zip`，完整解压，退出正在运行的图绳后运行 `Install.cmd`。更新保留程序目录中的 data 文件夹与已有设置。

压缩包随附 SHA256 校验文件。安装包不包含个人截图、设置或测试数据。
