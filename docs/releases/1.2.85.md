# PicRope 1.2.85

- 同月的归档文字合并保存到“归档/年/月/年-月.txt”，每条记录包含任务ID及完整任务详情，任务之间使用 `-----------------------------------` 分隔。
- 任务ID沿用初次创建时间，精确到秒；同秒重名增加序号，并避开已有归档文件和月度文件中的ID。
- 图文组合的文字保存到当月文本文件，图片以相同任务ID命名，存放在同一目录。
- 纯图片继续单独归档。已有旧版归档文件保持原样，新删除内容采用新格式。
- 月度归档使用临时文件和原子替换，保存失败保留原备忘。

## 安装与更新

完整解压 `PicRope-1.2.85-windows-x64.zip` 后运行 `Install.cmd`，或在托盘菜单中检查更新。更新保留现有数据、设置和归档。附带 SHA256 校验文件。
