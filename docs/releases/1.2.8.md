# PicRope 1.2.8

- 托盘右键菜单新增“删除时归档”开关，默认关闭并记住设置。
- 关闭归档时，文字、图片和图文备忘直接永久删除，不进入回收站、不弹确认框。
- 开启归档时，先保存到软件目录下的“归档/年/月”，再移除原内容；归档失败保留原备忘并提示。
- 文件名使用备忘初次创建的本地时间，精确到秒；图文采用相同文件名和各自扩展名，同秒冲突加相同序号。
- 编辑、排序、取下重挂不会改变已记录的初次创建时间。旧版本图片首次升级时按原文件创建时间补齐。
- 更多操作中，在“打开收集文件夹”下方新增“打开归档日志”，点击打开归档目录。

## 安装与更新

完整解压 `PicRope-1.2.8-windows-x64.zip` 后运行 `Install.cmd`，或在托盘菜单中检查更新。更新保留数据、设置和归档目录。附带 SHA256 校验文件。
