# 内容卡片开发计划

目标：默认关闭自动获取剪贴板；图片和文字各自默认自动上绳；支持手动粘贴、文字纸条、图片备注和已有内容关联。

约束：沿用 C# / WPF / .NET Framework 4.8；兼容已有 state.json；不改变图片原文件；复制软件内部内容不自动重复收集。

设计：保留现有图片文件列表和文字记录。新增图片备注、文字挂绳状态、文字自动上绳和混排顺序。图片＋备注只在篮子显示，纯文字在信封显示。关联沿用发起卡片的挂绳位置，合并前可追加/替换备注；拆分后保留两份内容。

- [x] 数据模型：新增兼容字段、混排、关联、拆分、独立移除；先写持久化和旧数据测试，再实现。
- [x] 挂绳：文字用真实 TextBlock 呈现；图片下显示备注摘要；完整查看、复制、取下和整体删除。
- [x] 剪贴板：同一次快照读取图片与文字；统一默认关闭开关；手动粘贴不受自动获取限制；分别遵循自动上绳开关。
- [x] 窗口：篮子与信封粘贴入口、信封自动上绳和选中挂上；已有内容关联/编辑/拆分界面。
- [x] 验证：核心、卡片模型、剪贴板载荷、界面与打包检查；备份安装目录数据后更新本机。

重点：剪贴板繁忙/改变、空文本、超长文字、图片＋文字格式、已有备注合并、保存失败回滚、恢复时不自动重新挂起、搜索框粘贴不被截获。

执行记录：在 feature/content-cards 分支开发；使用当前独立克隆目录，避免额外工作区权限及目录切换。上游文字动画测试曾超时，记录为基线问题，不以跳过失败宣称通过。
