# 信封左右布局与自动保存

基于最新 main 97e253c（1.2.5）。用户要求左侧单条摘要且不展开，右侧显示当前选择项完整内容并直接编辑，操作按钮保持同一行；用户选择自动保存。

实现：沿用 WPF 与篮子视觉样式，窗口扩大为最多 960×620 DIP；左侧摘要/时间/选择/复制删除，右侧多行编辑详情。自动上绳开关放标题栏，挂绳、粘贴、配图编辑、全选和批量删除放同一底栏。输入短暂停顿保存，切换与关闭前刷新保存；保存失败保留草稿并阻止丢弃。编辑框 Ctrl+V 使用普通粘贴，不创建额外记录。

执行方式：superpowers:executing-plans，当前新功能分支 feature/envelope-details。
