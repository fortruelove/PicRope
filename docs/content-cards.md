# 本地定制版 1.2.1：图文内容卡片

1.2.3：图片、文字与图文组合卡片直接拖动排序并保存；拖动期间对应夹子与整条绳子高亮，仅在挂卡区域内松开才排序，拖出到其他应用或取消不改序。文字批量删除取消二次确认。更新仓库改为 fortruelove/PicRope。

1.2.2：移除空绳提示框；托盘右键增加「置顶绳子」，勾选后立即展开并持续显示，重启后保留。取消勾选恢复自动收起；截图期间暂时隐藏，结束后恢复。

- 1.2.4 起，托盘「剪贴板收集」同一行提供「图片」「文字」两个独立开关，默认关闭。自动上绳仍由篮子和信封各自控制。旧统一开关开启时保留为两类都开启，之后各自记忆。
- 1.2.4 起，信封和篮子整体缩小为原来的一半，同时缩小点击区域并调整位置、挂绳占用宽度和弹窗锚点。
- 微信、QQ 等复制图片时，某个可选格式返回无效数据不会再中断整次读取；按有效 PNG/JPEG 等编码、Bitmap、DIB/DIBV5、图片文件逐级回退。仅开启文字收集时跳过图片解析。混合剪贴板中已失效的图片文件不影响文字。
- 篮子「粘贴图片」、信封「粘贴文字」均支持 Ctrl+V。信封搜索框内的 Ctrl+V 仍用于粘贴搜索词。
- 同一次剪贴板包含实际图片数据和文字时，生成图片＋备注卡片。网页若只提供图片网址，不会自动下载远程图片；先后两次复制不会自动配对。
- 纯文字显示为纸条；图片备注摘要位于缩略图下。单击图片复制图片，单击文字复制全文；组合卡片和文字双击可看完整内容。右键可选择复制文字或图文一起复制，粘贴效果由目标软件支持的格式决定。
- 图片右键「关联 / 编辑图文…」可以填写备注、从信封选文字，也能更换配图。文字可从信封选中后点击「配图 / 编辑…」，选择本地、剪贴板或篮子的图片。
- 合并沿用发起卡片的挂绳位置。已有备注可追加或替换；取消编辑不修改已有记录。
- 组合卡片统一挂上、取下和删除。右键可拆分，或仅移除备注、仅移除图片。仅移除图片会保留原文件，备注转为文字；整张删除时图片进回收站，备注删除。
- 自动收集忽略本软件写出的剪贴板内容；手动粘贴允许使用本软件复制的内容。

开发验证：在 PowerShell 7 运行 `./build.ps1` 和 `./tests/RunCardTests.ps1`。打包使用 `./package.ps1`。旧版 Windows PowerShell 可能误读上游无 BOM 的中文脚本，建议使用 PowerShell 7。
